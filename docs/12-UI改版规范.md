# 12 · UI 改版规范（v3，取代 docs/10 的“UI 设计规范”一节）

来源：用户提供的《Muster 个人 Agent UI 改版交接提示词》+ 两张参考图（主线、团队）。本文件是全体前端 agent 的唯一视觉依据；docs/10 中“渐变、毛玻璃、持续动画、StatCard 墙、Hero”等要求**全部作废**。

## 0. 判断标准
长期陪伴一个人的 Agent：亲近、安静、可靠，愿意常驻。优先级：**对话与结果 > 当前需要处理的事 > 任务进展 > 成员身份 > 汇总统计**。角色带来温度，背景保持安静。不做 KPI 墙，不做彩色玩具卡片。**一切数字/状态来自真实数据，不捏造**（没有可靠进度就写阶段，不写 60%）。

## 1. Token（`packages/ui/src/styles.css`，Tailwind 类名）
| token | 值 | 类名示例 | 用途 |
|---|---|---|---|
| canvas | #FCFBF9 | `bg-canvas` | 主背景 |
| sidebar | #F5F4F1 | `bg-sidebar` | 侧栏 |
| surface | #FFFFFF | `bg-surface` | 输入框、浮层、必要的独立容器 |
| surface-muted | #F2F3F5 | `bg-surface-muted` | 次要表面、代码背景、hover 底 |
| border | #E7E6E2 | `border-border` | 1px 轻边界 |
| text-primary | #24272C | `text-fg` | 标题、正文 |
| text-secondary | #626A76 | `text-fg-2` | 说明、元数据 |
| text-muted | #737983 | `text-fg-3` | 次级标签（不要再降透明度） |
| accent | #5976D9 | `bg-accent` `text-accent` | 主操作、选中、焦点 |
| accent-hover | #4964C3 | `hover:bg-accent-hover` | 主按钮悬停 |
| accent-surface | #EDF2FF | `bg-accent-surface` | 选中背景、用户消息底 |
| success | #28805D（底 #E8F4EE） | `text-success` `bg-success-surface` | 成功 |
| warning | #9A6700（底 #FBF1DC） | `text-warning` `bg-warning-surface` | 等待/待确认 |
| danger | #BA3F3B（底 #FBEAEA） | `text-danger` `bg-danger-surface` | 失败/危险 |
| 成员色 | cream #F6E3C2 / mint #BDE8D2 / peach #F9C3AC / sky #C3DDF7 / lilac #D9CEF5 | 仅 Pebble 与头像旁极少量身份提示 | |

- 只有一套强调色（accent 蓝）。成员色**只**出现在头像附近。状态 = 文字/图标 + 颜色，不只靠颜色。
- 字体：系统中文无衬线栈。页面标题 28–30/600；分组标题 16–18/600；正文 15–16、行高 1.6–1.75；侧栏 14；辅助 12–13。不要全页粗体。
- 间距 4/8/12/16/24/32/40/48。控件高 36–40；导航行高 40–44。圆角：普通容器 12，输入区 18，搜索浮层 18–20，按钮 8–10（不要处处胶囊，只有状态徽标与头像是圆）。
- **页面普通区域不使用投影**；只有浮层（搜索、弹窗、抽屉、下拉、Toast）用一层柔和投影 `shadow-overlay`。
- **禁止**：全屏彩色光晕、渐变标题/按钮、厚阴影、玻璃拟态、多层套卡、hover 上浮。
- 动效：只做必要的过渡（120–200ms）与浮层进出（200–240ms）；Pebble 动画低频、短暂、可关闭（设置 → 通用 → 减少动态效果，同时遵循系统 prefers-reduced-motion）。

## 2. 全局布局
- 侧栏展开 224px（216–232）、折叠 68px；`bg-sidebar`，右侧 1px border。顶部：品牌（Pip 小头像 + Muster，点击回 `/`）+ 全局搜索按钮（显示 ⌘K / Ctrl K 按平台）。
- 导航第一组：主线 `/`、团队 `/crew`、事件 `/events`、资源库 `/library`（**后端未实现：页面诚实空态 + 标注“即将推出”**）、设备 `/devices`。第二组“个人”：需要你 `/inbox`（待处理数）、记忆 `/memory`、技能 `/skills`、成本 `/costs`。“最近对话”默认 4 条，可展开更多。底部固定：设置 `/settings` + 一行连接状态（“Pip 已连接 / 连接中 / 已断开·重试”）。当前项：`bg-accent-surface text-accent`；其他图标中性灰。折叠快捷键 Ctrl/⌘+B（按平台展示）。
- 页面头栏 56–64px（标题 + 状态/操作，**无大 Hero**）。页面内边距 32（≥1600 宽屏 40）。管理页最大内容宽 1200（1120–1280）居中。对话正文宽 760（720–840）居中。
- 主线右侧上下文栏 300px（280–320），可收起（头栏按钮“打开/收起上下文”），状态持久化；并非所有页面都有右栏。
- 断点：≥1440 侧栏展开 + 按需右栏；1100–1439 右栏默认收起（按钮以抽屉打开）；768–1099 侧栏折叠、避免硬挤双栏；<768 导航抽屉 + 单栏，详情/审批独立视图。无水平溢出、无双重固定输入框；长代码与路径只在自身区域滚动。

## 3. 状态映射（全局唯一，`apps/web/src/lib/status.ts`）
任务：排队 queued / 执行中 running / 等你确认 waiting_approval / 已完成 done / 失败 failed / 已取消 cancelled（**暂停：协议暂无，不展示**）。成员：在线/离线/工作中/等你确认/空闲/休息中 由 bot.status 映射，与任务状态分开。颜色：执行中=accent，等你确认=warning，完成=success，失败=danger，其余中性。排序：等你确认 > 执行中 > 排队 > 失败 > 完成 > 取消。已完成任务不在“进行中”；等待确认不同时显示“正在执行”。

## 4. 逐页（详见交接提示词原文，以下为与本项目能力对齐后的结论）
- **主线**：轻问候 + 一行真实摘要（“1 项进行中 · 1 项等你确认”，去重计数）；对话唯一中心；用户消息右对齐 accent-surface 底；Pip 消息左对齐、无底或极轻底（白底 + 1px border）、无阴影。派发 = 一个任务组容器内的紧凑任务行（64–88px：头像、“成员 · 标题”、一行结果/阶段、文字状态徽标、一个“查看任务/查看结果”入口）。待确认在对话内是**一条琥珀提示行**（“阿克需要运行 pnpm install · 查看并确认”→ /inbox?id=），不放按钮组。右栏“此刻”：需要你 / 进行中 / 接下来（cron 触发器下一次时间，带具体日期）/ 成员（头像网格 + 状态）。输入区 96–120 起，自动增高有上限，@ 成员、语音（未实现则不显示）、发送；运行中可停止生成（task.interrupt）；滚动回看时出现“有新消息”按钮；IME 组合输入时 Enter 不发送。
- **任务详情**（工作台）：面包屑回主线；标题、负责人、阶段状态、打断/取消；左侧对话与步骤（实际里程碑，非伪进度），右侧产物/运行记录（改动、终端、日志）按任务类型出现（非代码任务不显示改动/终端）；补充要求/插问（steer/queue/interrupt）。
- **需要你**：待处理/已处理；详情：谁请求、来自哪个任务、会做什么（命令原文等宽可复制）、工作目录、风险；“仅允许这一次”/“拒绝”；处理中禁用；已过期/已被处理显示结果。**不提供“总是允许”**（后端不支持）。
- **团队**：Pip 协调者信息行 + 成员网格（宽屏两列）：头像、名称、专长、模型小标签、状态、一句介绍、技能、最近任务、“发消息/配置”（配置为抽屉）。添加成员抽屉（原生成员：人设/模型/工具；外部 Agent：检测结果）。
- **事件**：页签“动态 / 日程”。动态按今天/昨天分组，聚合高频工具事件，附来源任务与“继续对话”。日程：名称、频率、下次运行（带具体日期与时区）、启用、最近结果；新建/编辑用抽屉。
- **设备**：左列表右详情；真实在线/最后活跃；远程浏览器“未接入”短空态 + 连接步骤；配对码。不伪造“Agent 操作中”。
- **资源库**：空态（“任务产出的文档、图片会出现在这里”）+ 标注即将推出；不伪造文件、容量。
- **成本**：单一主数字（全部成员累计，标注“自守护进程首次启动起累计 · 估算 · USD”），按成员/任务明细表切换；**不画日线图**（无按日数据），无预算假数据。
- **记忆**：诚实空态（后端未实现），说明将来的确认机制不作承诺。
- **技能**：页签仅“已安装”（外部 Agent 检测 + SKILL.md 空态 + MCP 空态）；不做“发现”。
- **设置**：完整页面 + 二级目录：通用（外观/语言/发送方式/减少动态效果）、Pip 与成员（→ 团队页链接 + Pip 模型）、模型与连接（现有模型配置能力）、权限与安全（现有审批说明）、关于；消息渠道/通知/数据与存储：**未实现，不列入目录或明确标注未开放**。立即保存的设置显示保存状态，失败回滚。
- **全局搜索**：Ctrl/⌘K，居中 720 宽浮层，搜索页面、成员、任务、对话（已加载线程的消息），键盘选择、Enter 打开到具体对象，Esc 关闭恢复焦点，空结果与加载态。

## 5. 组件（`packages/ui` 与 `apps/web/src/components/common`）
AppShell、Sidebar、PageHeader、ContextPanel、Composer、MessageItem、TaskRow、StatusBadge、ApprovalDetail、MemberAvatar（Pebble）、SettingsSection/SettingsRow、CommandSearch、EmptyState（小头像/线性图标 + 一句话 + 一个操作）、Drawer、Dialog、Toast、Tabs、Switch、Select、Input/Textarea、Button（primary/secondary/ghost/danger，高 36/40，圆角 8）。

## 6. 代码洁净
本次改版**删除**一切不再使用的旧代码：渐变/毛玻璃/光晕类、hover-lift、StatCard/Hero/Sparkline/AnimatedNumber 等 KPI 组件、持续动画关键帧、未被引用的组件与工具函数、过时测试。每个 agent 交付时自查：`git grep` 无引用的导出必须删除；不留注释掉的代码；不留 TODO 式占位 UI。
