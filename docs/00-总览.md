## 一句话定位

**你的电脑们、你的编程 agent 们，由一个会说话、会表情、你能随时插话和分叉的 Bot 团队统一管起来——开源、可自托管、每一步都可审计。**
（英文：*Your machines and your coding agents, run as one crew you can steer, fork and audit.*）

不是又一个聊天机器人，也不是又一个 IDE：它是**个人 Agent 指挥台**。主 Bot 极轻，只做分发；真正干活的是有状态的子 Bot——包括本机的 Claude Code、Codex、OpenCode、Goose 等外部编程 agent，也包括自带的研究/办公 Worker；多台电脑与远程浏览器是它们的"手"。

## 核心结论摘要

### 选型
- **核心**：Rust 单进程 daemon（`musterd`，可无头部署）+ 协议化薄 UI 壳。UI 只依赖自有 WS 事件协议，换壳不返工。
- **桌面壳**：Tauri 2 + React/TypeScript（保留 Electron 回退，双内核 CI）。移动端 = PWA 遥控器，Agent 永不在手机上跑。
- **内核**：自建薄内核（SQLite WAL 单写者事件日志 + 收件箱 + effect outbox + 调度），其余库级复用：`rusqlite`、`rmcp`（MCP）、`agent-client-protocol`（ACP，已核实包名）、`iroh`（P1）、`rig-core`。**M0 两周止损闸门**，失败则以 DeepSeek Harness（MIT）作 Router 内核。此项偏离了你"基于成熟项目二次开发"的字面诉求，需你确认（Q1）。
- **外部编程 Agent**：内部 canonical 事件 + ACP 南向 + 原生逃生舱（Codex 走 `app-server`，Claude 走 `claude-agent-acp`，OpenCode/Goose 走 ACP）；能力矩阵与显式降级。
- **多机**：Hub / Node / Operator 三角色；Ed25519 设备身份；两层审批（设备准入 + 能力面）；审批在 Node 本机强制。
- **远程浏览器**：统一 `browser.*`，三档后端（隔离 profile / 真实 Chrome / 云 CDP）；v1.0 做 A（隔离 profile）+ C（云 CDP），B（真实 Chrome）后置。

### 架构（SuperAgent 哲学的落点）
- **主 Bot 极薄**：无 Bash、无写权限，规则快路径优先、LLM 慢路径兜底。
- **子 Bot 有状态**：追加式会话日志；`fork`（外部引擎原生 fork + worktree + turn 级快照）、`steer/followup/interrupt`、悬空 tool call 补合成结果。
- **一切皆事件**：用户输入、cron、GitHub PR、子 Bot 回调、设备上下线、审批结果同构，幂等入库、可重放、哈希链审计；订阅直通 + 授权/订阅分离；外部触发默认 `observe`。
- **安全默认**：确定性策略引擎（R0–R5）、原生审批卡、无人值守自动拒、不可信来源标记、凭据句柄、worktree 非安全隔离（已纠正）。

### 差异化（对标 Meta Muse / Grok Bot / OpenClaw）
1. 指挥你自己的 Claude Code/Codex/OpenCode/Goose，而不是再造一个编程 agent。
2. 分支 + 插话 + 打断是产品原语，不是隐藏功能。
3. 你自己的机器网格，P2P/自带 overlay，设备间不经第三方存数据。
4. 默认询问、哈希链审计、可自托管；安全不设付费墙。
5. 事件驱动的常驻性：PR、cron、回调统一事件化。
6. 成本透明：任务级预算、循环检测。
7. 头像即状态：L0 参数化形象 + 一只原创吉祥物（Pip：卵石 + 天线芽 + 圆珠眼）。

## 评审要点（详见 05）
- 发现 **19 处矛盾、15 处遗漏、10 处不现实、8 项法律/许可风险**，已就地修订四份设计文档。
- 重要纠正：worktree 不是沙箱；"从此处分支"必须有 turn 级文件快照；vendoring Codex 沙箱 crate 依赖链很深；PWA 需要 HTTPS 才有推送；`claude-agent-acp`/Playwright 需要 Node 运行时（受管运行时下载）；Claude 订阅模式属合规灰区，验收只在 API Key 模式。
- 代号已统一为 Muster（Pip 仅为吉祥物/主 Bot 名）。
