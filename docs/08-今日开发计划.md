# 08 · 今日开发计划（2026-11-06，单人 + 多 Agent 并行）

目标：一个下午做出**可演示的纵向切片**，不是完整产品。

**切片验收（Definition of Done）**
1. `pnpm desktop` 打开 Electron 窗口，自动拉起 `musterd`，界面按概念稿（`design/mockups/*.png`）呈现。
2. 在主线对 Pip 说“交给小码修 xx，交给阿克写 yy”→ 出现两张派发卡，两个子 Bot 并行工作（脚本化的 fake 引擎必须能跑；真实 Codex / Claude 驱动尽力接通）。
3. 在子 Bot 工作台可以**插话 / 排队 / 打断**，可以**从某一步分支**成新任务，并在分支页对比。
4. 子 Bot 请求权限时出现**审批卡**，允许/拒绝生效；无人值守触发的审批自动拒绝。
5. **定时 / GitHub / 设备上线 / 子 Bot 回调**都作为事件出现在事件中心；触发规则可编辑，观察 / 询问 / 自动三档语义正确。
6. 杀掉并重启 daemon，任务和会话记录不丢。
7. 团队 / 设备 / 技能 / 设置 / 收件箱 / 成本 / 记忆 / 首次引导页都可打开，数据来自协议，不是写死。

**明确不做**：云端托管、真实多机配对（只做设备页和配对码占位）、远程浏览器、语音、Rive 动画、手机原生壳（Web 响应式后置）、插件市场。

## 通用规则（所有 Agent）
- 只改自己独占的目录。需要改契约时：追加**可选**字段并在 `packages/protocol/CHANGES.md` 记一行，其余不动。
- 安装依赖只能用 `node scripts/pnpm-locked.mjs add -F <pkg> <dep>`（串行化，避免锁文件冲突）。
- 不要 `git commit`、不要 `git add`、不要改别人目录；不要运行长期驻留进程而不清理；测试用随机端口（port 0）。
- 完成标准：自己的包 `typecheck` 通过，有测试的写测试且 `vitest run` 通过。
- 写文件用 Write/Edit 工具，不要用带引号的 bash heredoc（Windows bash 上会出错）。
