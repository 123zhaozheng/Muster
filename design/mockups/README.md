# Muster UI 概念稿（2026-11-06）

由 `scripts/gen_mockups.py` 调用图像模型生成，提示词见 `prompts.json`。风格参考 Lovable / Meta Muse：暖白底、柔和渐变光晕、毛玻璃卡片、大圆角、珊瑚橙主色 + 薰衣草紫辅色，卵石小生物形象。
